Dua · sab se pehle yeh parho

Is site se video kaise banani hai?

Dua, is site ko upar se neeche follow karna hai. Tumhein script likhni, English samajhni ya timing calculate nahi karni. Har jagah jo button aur file naam diya hai, bas wahi use karna hai.

Sab se zaroori baat: yeh site khud video nahi banati aur tumhari files save nahi karti. Yeh tumhein tayyar script, image prompts, timings aur upload text deti hai. Awaaz F5-TTS mein, images Tensor.art mein aur final video CapCut mein banti hai.

Exact tested settings

F5-TTS voice

  • Voice: bm_mix_adam_lewis
  • Speed: 0.8
  • Rule: har Long aur har Short mein yehi voice aur speed rakho.

Tensor.art image

  • Model: Juggernaut XL-Ragnarok
  • Sampler: DPM++ SDE Karras
  • Sampling steps: 25
  • CFG scale: 4
  • Images: 1

  • Positive box: page ka main image prompt.
  • Negative box: page ka “Negative prompt” alag paste karo. EasyNegative chip select mat karo.
  • Free check: Generate button par 1 credit nazar aaye; PRO badge ya 25 se zyada steps select mat karo.
02

Pehli dafa kya karna hai?

  1. Channel setup page kholo.
  2. YouTube ka name, handle, description, profile aur banner set karo.
  3. TikTok ka nickname, username, bio aur privacy settings set karo.
  4. Yeh setup sirf ek dafa karna hai. Har video ke liye dobara nahi.

04

Long video ka poora order

  1. Calendar kholo aur jis week par kaam karna hai woh dekho.
  2. Lambi videos kholo aur us week ka Long page kholo.
  3. 01 Script: “Script copy karo” dabao. Sirf English script copy hogi.
  4. F5-TTS: F5-TTS kholo, script paste karo, voice bm_mix_adam_lewis aur speed 0.8 select karke audio banao. Download ka naam page par diya hoga, aam tor par voice.
  5. Wapas Long page par aao. 02 Awaaz upload mein wahi MP3 select karo. Page ke saare timings ab asli voice ke mutabiq update honge.
  6. 03 Images: pehla prompt copy karo, Tensor.art kholo, upar wali exact tested settings aur size 1280 × 720 rakho. Image download karke naam 01 do. Isi tarah 40 tak.
  7. Image mein readable text, logo, extra haath, ghalat face ya broken object ho to us image ko dobara generate karo.
  8. 04 CapCut: naya 16:9 project. Voice ko zero se lagao. Timing table ke mutabiq 01–40 images lagao.
  9. Har image ko dheema zoom do. Export 1080p, 30fps aur Long folder mein save karo.

Yaad: voice upload karne ka matlab website par awaaz bhejna nahi. Browser file ki duration parhta hai aur sirf tumhare phone par timings update karta hai.

05

Teen Shorts ka poora order

  1. Choti videos kholo.
  2. Usi week ka Short 01 kholo. Script copy karke F5-TTS mein bm_mix_adam_lewis, speed 0.8 se voice banao. Page ka exact filename rakho.
  3. Voice Short page par upload karo taake timing update ho.
  4. Page par Long ki 8 image numbers likhi hongi. Pehle wahi images use karo. 9:16 crop mein subject kat raha ho to sirf woh image Tensor.art se vertical dobara banao.
  5. CapCut mein naya 9:16 project. Voice zero se, phir timing ke mutabiq 8 images.
  6. Export 1080p, 30fps aur Short 01 folder mein save.
  7. Bilkul isi order se Short 02 aur Short 03 banao.

Ek week tab complete hai jab 1 Long aur 3 Shorts export ho chuki hon.

06

Background music kaise lagani hai?

  1. Background music page kholo aur apna week dekho.
  2. Track ka source/download page kholo. Audio download karo aur license ka screenshot save karo.
  3. CapCut mein music ko voice ke neeche lagao.
  4. Music volume 5% se shuru karo. Voice bilkul clear rehni chahiye; zaroorat ho to music aur kam.
  5. Music chhoti ho to clean loop lagao aur video ke end par fade out.
07

YouTube aur TikTok par upload

  1. SEO packs kholo aur wahi week kholo.
  2. Long ko YouTube Long card se upload karo. Final title, description, tags, hashtags, thumbnail text aur settings alag alag copy karo.
  3. Har YouTube Short ke liye usi Short number ka YouTube card use karo.
  4. Har TikTok Short ke liye usi Short number ka TikTok card use karo.
  5. Thumbnail ya cover prompt se image banao. Prompt ke andar text generate mat karwao; diya hua text CapCut mein khud lagao.
  6. Upload pehle Private rakho. Title, captions, cover, audio aur ratio check karo. Phir Schedule ya Public.
08

In alfaaz ka matlab

Script

Woh English kahani jo F5-TTS ko deni hai.

Prompt

English instruction jo Tensor.art ko image banane ke liye deni hai.

Negative prompt

Woh cheezein jo image mein nahi chahiye. Isay alag Negative box mein paste karo; Positive prompt ke saath chipkao mat.

Timestamp

CapCut timeline ka waqt, jaise 0:47. Usi waqt nayi image lagti hai.

16:9

YouTube Long ki horizontal video.

9:16

YouTube Short aur TikTok ki vertical video.

Thumbnail / Cover

Video kholne se pehle nazar aane wali image.

Captions

Video par voice ke English words. Publish se pehle spelling check karni hai.
